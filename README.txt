AUSTRALIAN TRAIN SPOTTER — iPHONE WEB APP PROTOTYPE

Included:
- Add, edit, search and delete locomotive records
- Australian states and territories
- Multiple photos per locomotive
- Sightings diary with date/time, location and notes
- Collection counts
- JSON backup/export
- Home Screen web-app manifest and offline app shell

IMPORTANT:
This is a prototype, not yet hosted online. To install it as a Home Screen web app, it must be uploaded to an HTTPS web host. Then open its HTTPS address in Safari on the iPhone, tap Share, and choose Add to Home Screen.

Data is stored in the browser on that device using IndexedDB. It is not automatically synced or backed up to iCloud. Use Backup regularly and keep the exported JSON file somewhere safe. The backup includes the photos and may be large.

The app has not yet been independently security-reviewed or tested on a range of iPhone models. Test with non-critical sample data first.
